# Soenneker.Blazor.SignalR.CredentialsHandler

A custom DelegatingHandler that modifies outgoing HTTP requests to include browser credentials.

## Install

```bash
dotnet add package Soenneker.Blazor.SignalR.CredentialsHandler
```

## What you get

- `IBlazorSignalRCredentialsHandler` — A custom DelegatingHandler that modifies outgoing HTTP requests to include browser credentials.
